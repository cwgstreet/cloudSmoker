# Temperature Probe Labels

The **cloudSmoker2** firmware provides the facility to add in measured probe-specific calibration factors, in order to improve measurement accuracy. 

If you choose to calibrate your probes, you will need to be able to consistently identify specific probes as the measured calibration factors are unique to that probe.

I used an open-source cable tag, [ZipTag v2.0](https://www.printables.com/model/607312-ziptag-v20) by [Rob Smo](https://www.printables.com/@RobSmo)
to create zip-tie labels for the four temperature probes:
1) PIT
2) MEAT1
3) MEAT2
4) MEAT4
