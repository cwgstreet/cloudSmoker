# Probe Spools - 3D Print Models

CapnBry of HeaterMeter project fame, created a design for temperature probe spool holders that I adopted for cloudSmoker2.

The print files here are for a 4-probe sppol holder - basically three base spools and an end-cap that fit together.

You can also download the probewrap.scad file from Thingiverse (link below) and further customise the spools using open source OpenSCAD software or the Thingiverse customisation tools - for example if you want to only have a two probe (Pit and Meat1) spool or if you need to change model dimensions like probe diameter.

The provided model works well with Maverick ET-731 / 732 style temperature probes.
